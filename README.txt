PYTHON 35 PRACTICAL PROGRAMS
============================

Contents:
- 35 practical files covering Python, Jupyter, NumPy, Pandas, Matplotlib,
  Seaborn, Scikit-learn, CSV data analysis, and visualization.
- students.csv is included for Programs 11-31 and 33-35.
- requirements.txt contains the required Python libraries.

SETUP
-----
1. Open Command Prompt/Terminal in this folder.
2. Create a virtual environment:
   python -m venv myenv

3. Activate on Windows:
   myenv\Scripts\activate

4. Install libraries:
   pip install -r requirements.txt

5. Run any program, for example:
   python 01_python_version.py

JUPYTER
-------
For Program 8:
   jupyter notebook
Then open 08_first_jupyter_program.ipynb.

IMPORTANT
---------
Programs 11-31 and 33-35 expect students.csv to be in the same folder.
